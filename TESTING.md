# Testing the book

For each test photo (aim for 5+, different kids/people, with permission), make Jack, paint pages 1–3, download the PDF, and check:

| Check | Page 1 | Page 2 | Page 3 |
|---|---|---|---|
| Jack's face matches the reference and the photo | | | |
| Same clothes as the reference | | | |
| Scene matches the storyboard | cupboard, mother, cow through door | old man, five colored beans, rope | mother at window, beans flying, Jack in doorway |
| Text area is calm and the words read clearly | lower third | sky | dark grass |
| No lettering drawn in the art | | | |
| Mood | warm daylight | bright midday | darker dusk |

Also check across pages: the mother looks the same on 1 and 3, the cow on 1 and 2.

Record what went wrong and what you changed in the log in `PROMPTS.md`.
